## 2. 特にユーザー判断を仰ぎたい最重要事項（実装ブロッカー）

作業7B〜7C を進行させるにあたり、開発側の推測で確定してはならない（第18節・第21節）核心判断事項は以下の **5グループ** である。

1. **開始時手順・非スクリプト切札（`Q-001`, `Q-002`）**:
   - Setup UI 上で「全54種から切札2枚を自由選択可能（非スクリプト 22種＋Joker を選んだ場合は効果なし・汎用操作対象可 or 対象外）」とするか、あるいは非スクリプト札の選択自体に警告・補足を表示するか。
   - プリセット兵士（Step 9〜10）の表向き化はチャージ状態＋不適格時引き直し＋Turn 1 即攻撃可能で確定してよいか。
2. **エンド時誘発 `通常` アクションの Stage LIFO 問題（`Q-003`）**:
   - `手札補充`, `充足`, `幻影` は公式 YAML 上 `@誘発-通常-クイック` かつ `エンドをリクエストした時に誘発する` となっているが、コアフロー文字通りの `[4]→[5]→[9]` では `エンド` より後に解決して破綻する。Simulator 側で「`エンド` より先（ステージ上）に積む／解決させる」仕様補正を入れてよいか（かつ将来公式ルールへ修正提案するか）。
3. **サブリクエスト系の例外境界（`Q-004`, `Q-006`）**:
   - `追撃` が生む `アタック` は「1ターン1回」制限を突破できるか、また攻撃可能兵士 0体時に発動可能か。
   - `修繕` における墓地カード選択は「該当カード存在時は強制」でよいか。
4. **破壊・無効化・全領域探索の厳密対象（`Q-005`, `Q-007`, `Q-008`）**:
   - `カウンター策士召喚` が「カウンターの対象にならない」カードを無効化できるか、該当リクエスト 0件でも召喚できるか、無効化時キーカードは墓地送りか。
   - `破砕士召喚` の防壁選択者は発動者か相手か（Issue `#644`）、敵防壁0・自防壁1以上で強制自壊か、場全体防壁0で素出し可か。
   - `魔王召喚`/`巨人召喚` で場の装備中ユニットや裏切札から `♣K`/`♢K` を引き抜く際の処理および公開領域優先探索の是非。
5. **その他確認事項（`Q-009`〜`Q-014`）**:
   - `救済` の「数字以上」（現在サイズ vs 印刷数字）、`巨人` の強制アタックタイミング（ターン中必須 vs 初手必須）、`暴動` のコスト `$D` 誘発可否。
