## 5. 注意事項（即時アクション内インタラクティブ選択の設計検証）

棚卸し結果から判明した重要な設計注意点として、**`先読み`（#44：`即時-クイック`）** と **`援軍`（#19：`通常-メイン`）** について以下に差異がある：
- `援軍`（`通常`）は Stage 解決中の中断再開を `EffectContinuation` が標準サポート済み。
- `先読み`（`即時-クイック`：`ライフ上2ドロー → 手札1枚選びライフ上/下へ`）は、**トリガーによる即時（`TriggerProcessingCoordinator`）ではなく「直接アクションの即時（`CommandRegistry.resolveImmediateRequest`）」** であるため、現行 Core で直接即時アクションが途中で `WAITING_FOR_DECISION`（手札1枚＋上下選択）を返す経路（`GameSession` 上の即時解決中断再開）が作業6の範囲に確実に組み込まれているか作業7B で詳細点検し、必要なら中断再開可能な通常経路と同一の `EffectInterpreter` ループを通すこと。
- 同様に、`クイックオープン` / `メインオープン` / `瞬殺` / `悪あがき` / `リセット` 等、**直接-即時アクションで効果内選択・相手選択を伴うもの** はすべて「直接即時でも選択ステップで `WAITING_FOR_DECISION` → 再開」ができる設計が必要となる（作業6で `resolvingRequest`＋`EffectContinuation` は即時/通常双方の土台を備えている）。
