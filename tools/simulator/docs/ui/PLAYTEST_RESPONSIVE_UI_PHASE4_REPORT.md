本作業では、BlackPoker Playtest 画面における文字サイズ変更（`100%` / `115%` / `130%` / `150%`）の4段階スケーリングと、`localStorage` による設定保存・復元基盤、および7つの検証対象解像度 × 4段階文字倍率（**計28組み合わせ**）の実ブラウザー検証を完了しました。

### 1.1 主な達成事項
1. **ユーザー設定保存基盤 (`PlaytestUserPreferences.ts`) の構築 (Phase 4A):**
   - `schemaVersion: 1` による設定スキーマを策定。将来の Phase 5（`graveTopSelectionMode`）拡張用スロットを内包。
   - 6大動作保証（即時反映、リロード時復元、新規対戦開始時維持、破損JSON時フォールバック、localStorage例外安全、不正値サニタイズ）を完全保証し、単体テスト全19件PASS。
2. **CSS変数 `--bp-font-scale` によるコンテナスコープ・タイポグラフィ改善 (Phase 4B):**
   - `html` ルート font-size の変更、CSS `zoom`、`transform: scale()` による画面全体の安易な拡大を厳格に排除。
   - Playtest ルートコンテナ（`playtest-root-container`）配下のフォントクラスに対して `--bp-font-scale` を安全に適用。
   - 操作に必要な文字（決定、PASS、アクション名、対象、コスト）は標準 100% で 12〜14px、補助ラベルは 10〜11px 以上を確保。
   - バッジやボタンの固定高（`h-4`, `h-5` 等）を `min-h-*` / `py-0.5` / `leading-snug` に置換し、150% 拡大時でも文字クリップをゼロに抑制。
   - `130%` / `150%` 拡大時には、デスクトップ2ペイン固定高（`lg:h-screen lg:overflow-hidden`）から安全なページスクロール（`min-h-[100dvh] overflow-y-auto`）へ自動フォールバック。
3. **統合設定メニューへの「表示設定」追加と28組み合わせ実ブラウザ実測 (Phase 4C):**
   - 統合メニュー内に 4段階ピルボタン（100% 標準 / 115% 中 / 130% 大 / 150% 特大）、現在値バッジ、「標準に戻す」ワンタップボタンを実装。即時プレビューと自動保存を実現。
   - 実ブラウザー（Playwright）を用いて 7解像度 × 4倍率 = **全28組み合わせ** の DOM 座標・寸法を精密実測。
   - **全28組み合わせで横スクロール（横溢れ）ゼロ（28/28 PASS）**、**主要操作ボタン（決定、PASS、Undo）到達性100%（28/28 PASS）** を確認。
   - 150% 拡大時に決定ボタン内ラベル幅が `84px` から `126px` へ **正確に +50.0% (1.5倍)** 拡大していることを実測確認。
   - モバイル表示時（`390x844`）における選択マーカー `①`/`②` とカードラベル（`一般兵`）の重なりを解消（間隔 `1.75px` の安全クリアランス確保）。
   - `1023px ↔ 1024px` ブレークポイント跨ぎ時の `draftStateRef` によるアクション・コスト・対象選択状態の維持を確認。

export interface PlaytestUserPreferences {
