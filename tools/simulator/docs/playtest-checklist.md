# Core Battle Playtest: 有識者向け動作確認チェックリスト

このチェックリストは、BlackPoker のルール有識者・開発者がブラウザ上でプレイテストを行い、コアフローとルール処理の正確性を検証するためのものです。

---

## 1. コアフロー & 進行

- [ ] **誰のチャンスかが明確か**: 画面上部のチャンスバナーで現在判断権を持つプレイヤーが一目でわかるか。
- [ ] **手番 (Turn Player) とチャンス (Chance Player) の区別**: 手番プレイヤーとチャンスプレイヤーが別々に正しく表示されているか。
- [ ] **PASS のタイミング**:
  - ステージが空の状態で手番プレイヤーが PASS すると、相手へチャンスが渡るか。
  - ステージにアクションがある状態で PASS すると、相手へ対応機会が渡るか。
  - 連続 PASS が成立した瞬間にステージ最上段のアクションが解決されるか。
- [ ] **Stage の積まれ方と解決順序 (LIFO)**:
  - 通常アクション発動時に Stage に積まれるか。
  - 後から割り込んだ Quick アクションが TOP に積まれ、先に解決されるか。

---

## 2. アタック (Attack)

- [ ] **アタッカー選択**:
  - チャージ状態かつ攻撃ラベルを持つキャラクターのみが候補に表示されるか。
  - 複数アタッカー（例: 2体同時アタック）が選択可能か。
  - アタッカーがドライブ（横向き）状態に変化し、`⚔ ATTACKER` マーカーが付与されるか。
- [ ] **0体アタック**: 0体を選択した場合、戦闘が発生せず安全に解決されるか。

---

## 3. ブロック (Block)

- [ ] **ブロック誘発**: アタック解決後、防御側の誘発アクションとして Block が自動的に積まれるか。
- [ ] **対応機会**: Block が積まれた直後、攻撃側に Quick 等の対応機会（チャンス）が与えられるか。
- [ ] **ブロッカー選択**:
  - 防御側のチャージ状態・防御ラベルを持つ兵士・防壁が候補に表示されるか。
  - 任意のアタッカーに対してブロッカーを割り当てられるか（複数兵士ブロック、0体ブロック含む）。
  - ブロッカーがドライブ状態に変化し、`🛡 BLOCKER` マーカーが付与されるか。

---

## 4. ダメージ判定 (DamageJudge)

- [ ] **自動誘発**: ブロック解決後、ダメージ判定が自動的に Stage に積まれるか。
- [ ] **兵士 vs 兵士**:
  - サイズが大きい方が生存し、小さい方が墓地へ送られるか。
  - 同サイズ（相打ち）の場合、双方が墓地へ送られるか。
- [ ] **兵士 vs 防壁**:
  - 防壁の記載ランクと一致するカードがアタッカーにある場合、防壁が破壊されて墓地へ送られるか。
  - 不一致の場合、防壁が生存しアタッカーが墓地へ送られるか。
- [ ] **未ブロック攻撃**: 未ブロックのアタッカーのサイズ分、防御側プレイヤーのライフが直接減少し、墓地へ送られるか。
- [ ] **戦闘クリーンアップ**: ダメージ判定解決後、アタッカー・ブロッカーの戦闘状態（マーカー）が解除されるか。

---

## 5. ターンサイクル (End → Charge → Draw)

- [ ] **エンド宣言**: 手番プレイヤーが「エンド」を選択・解決すると、ターンプレイヤーが交代するか。
- [ ] **チャージ即時解決**:
  - エンド解決直後、新ターンプレイヤーのフィールド全キャラクター（ドライブ状態）が一括でチャージ状態（縦向き）に復帰するか。
  - チャージは Stage を経由せず即時実行されるか。
- [ ] **ドロー誘発 & 対応機会**:
  - チャージ解決後、ドローが通常アクションとして Stage に積まれるか。
  - ドローが積まれた直後、対戦相手（新非ターンプレイヤー）に Quick 対応機会（チャンス）が渡るか。
- [ ] **ドロー解決 & 枚数判定**:
  - 全員 PASS 成立後にドローが解決され、ライフ山の一番上から手札に加わるか。
  - 解決時ライフが 3枚以上の場合は 2枚、2枚以下の場合は 1枚ドローされるか。
  - ドロー解決後、チャンスが手番プレイヤーに戻るか。

---

## 6. 勝敗判定 & 再戦

- [ ] **勝敗判定 (FINISHED)**: ライフが 0 になった瞬間に自動的にゲームが終了し、勝者オーバーレイが表示されるか。
- [ ] **再戦 (Replay)**: 「もう一度対戦する」ボタンを押すと、初期状態から新しいセッションで対戦が再開できるか。
