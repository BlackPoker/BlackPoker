## 3. 実装内容詳細

### 3.1 診断Fixtureの正規化 (事前準備)
- **正規トランプランクの適用:** BP-AI-14で手動生成されていた非正規のランク`"1"`カードを廃止し、正規のトランプエース（`rank: "A"`, `value: 1`）を使用。
- **サイズ2一般兵士シナリオの追加:** サイズ1だけでなく、サイズ2の一般兵士（`rank: "2"`, `value: 2`）による自滅攻撃シナリオも追加。
- **Joker数値の統一:** Jokerカードの数値を`20`ではなく公式仕様通り`0`として扱うよう整合。
- **Core正規生成の統一:** `state: any`による手作業の合成DecisionRequestを脱し、Coreの`LegalPatternGenerator.generateActionRequestDecision`および`generateBlockAssignmentDecision`を通した公式データ型による正規局面生成に統一。
- **R2エビデンスの保護:** R2の診断エビデンス（`gen9_behavior_quality_audit_work57a_r2.json`）を上書きせず、Work 5-7B専用のエビデンスファイル（`gen9_final_behavior_improvement_work57b.json`）へ新規出力。

### 3.2 P0-1: 不合理なアタックの回避
1. **空集合アタックの回避:**
   - 自軍の攻撃可能兵士が0体の場合、攻撃アクションにベースバイアス相殺ペナルティ（`-0.50`）を適用。
   - これにより、アタッカー不在時の空アタックを回避し、エンドや安全手を確実に選択。
2. **完全犬死アタック（`maxMyAtk < minOppBlk`）の回避:**
   - 自軍の全アタッカーが相手のどのブロッカーよりも小さく、未ブロック突破もない場合、失われる自軍戦力に応じたペナルティ（`-(0.50 + 0.05 * lostSizeSum)`）を適用。
   - ベースDNAが持つ積極攻撃バイアス（約`+0.40`）を確実に相殺し、アタックの最終スコアをマイナス（約`-0.12`〜`-0.20`）へ転落させる。
   - これにより、エンド（`+0.06`）や防壁セット（`+0.16` / v7.3で`+0.11`）を確実に下回り、自滅攻撃を完全に回避。
3. **有利戦闘・相打ち・リーサルの正常許容:**
   - 相手ブロッカー不在時の攻撃加点（`+0.20`、リーサル時`+2.0`）を維持。
   - 数的優位・未ブロック突破時の加点（`+0.25`、確定リーサル時`+2.5`）を維持。
   - 相打ち可能（`maxMyAtk >= minOppBlk`）な有効戦闘に対する加点（`+0.05`）を維持。

### 3.3 P0-2: 攻撃魔法の効果評価 (汎用DSL解釈)
1. **アーキテクチャ境界とDSL解釈:**
   - 特定カード名のハードコードを厳禁とし、YAML DSL（`dealDamage`, `moveUnitCardsToZoneTop`, `guardCondition`等）を汎用評価する`GenericTacticalEvaluator.evaluateProactiveAction`を新設。
   - `TacticalEvaluator`インターフェースを介して`Gen9TacticalPrototypePolicy`（v7.2）および`Gen9LearnableTacticalPolicy`（v7.3）へ注入。
2. **効果別の戦術補正:**
   - **確定致死リーサル:** 相手への直接ダメージが観測相手ライフ以上（`dmg >= oppLife`）の場合、**`+2.5`** を加点。ベースDNAの魔法消極バイアス（`-0.48`）を圧倒し、最終スコア`+2.02`〜`+2.37`で最高評価へ浮上。
   - **非致死直接ダメージ:** `Math.min(0.60, 0.04 * dmg)` を加点（13点なら`+0.52`）。
   - **相手兵士除去ボーナス:** 除去される相手兵士サイズに応じ `Math.min(0.50, 0.04 * size)` を加点（サイズ10兵士なら`+0.40`）。
   - **相手ライフトップ移動相殺:** 相手ライフが1枚増える効果に対し `-0.05` を相殺。
   - **合計加点:** ♠K＋♢Aの死の槍（サイズ10大型兵士）の場合、`+0.52 + 0.40 - 0.05 = +0.87`。ベース`-0.48`を加味した最終スコアは`+0.39`となり、エンド（`-0.15`）を確実に上回り死の槍が選択される。
3. **ガード条件不発の無駄撃ち回避:**
   - ガード条件が不発（例: ♢3でサイズ10兵士 $\rightarrow$ $10 \% 3 \ne 0$）の場合、戦術加点を`0`とする。
   - ベースの消極バイアス（`-0.48`）がそのまま維持され、エンド（`-0.15`）を下回るため、無駄撃ちを自動的に回避。
4. **キーカードと独立コストの分離:**
   - 死の槍のように独立コストが存在せずキーカードのみを消費するアクションにおいて、誤ったコスト支払いペナルティを課さないよう整合。

## 5. 見送った改善項目と理由

- **安全圏での不要なブロック抑制 (BP-AI-05):**
  - 自軍ライフに余裕がある局面での過剰ブロック抑制は、防衛アルゴリズムの安全マージン（致死漏れ防止）とトレードオフ関係にある。
  - 今回の主目的である「人間が自然に対戦できる水準」において、過剰ブロックはゲーム進行を破壊する致命的障害ではなく、保守的なプレイスタイルとして許容可能である。
  - 無理に抑制パラメータを導入すると、既存の致死防御ブロック（BP-AI-01）の堅牢性を損なうリスクがあるため、指示書の任意改善規定に基づき見送った。
