## 3. カテゴリ別詳細分析

### カテゴリ A: 防御・ブロック (BP-AI-01 〜 BP-AI-05)
- **合理的だった点:**
  - **BP-AI-01（致死防御: P0）:** 通常パターン列挙およびストリーミングブロック（`blockAssignmentStream`）の双方でブロック（ref 0, スコア 0.4596）を選択。PASS（ref 1, スコア -0.1821）には致命傷減点（$t_{15} = -2.5$）が正常に機能。
  - **BP-AI-02（防壁相打ち: P1）:** 非公開手札を覗くことなく、相手アタッカー（サイズ3）に対して防壁ブロック（ref 0, スコア 0.4584）を選択。
  - **BP-AI-03（大型兵士ブロック: P1）:** 相手サイズ2アタッカーに対し、小型兵士（サイズ1）の犬死を避け、大型兵士（サイズ4）による一方的撃破（ref 0, スコア 0.4054）を選択。
  - **BP-AI-04（複数兵士合算ブロック: P1）:** 相手サイズ5アタッカーに対し、単体犬死（サイズ3）を避け、2体合算（合計サイズ 3+3=6 >= 5）ブロック（ref 0, スコア 0.4054）を選択。
- **判断ミス・課題:**
  - **BP-AI-05（不要なブロック回避: P1 / AMBIGUOUS）:** 自ライフ15で全く危険がない状況でも、相手のサイズ1攻撃に対して自軍の小型兵士でブロック（ref 0, スコア 0.4440）してしまい、PASS（ref 1, スコア -0.1333）を選ばない。原因は「ブロック行動全般に対する正のバイアス」が一律に働いているため（原因C）。自ライフ安全圏におけるブロック抑制が望まれる。

### カテゴリ B: Counter・回避 (BP-AI-06 〜 BP-AI-08)
- **合理的だった点:**
  - **BP-AI-06（投擲へのCounter: P0）:** 自ライフ2（被弾で敗北）の局面で、相手の投擲に対し手札のCounter呪文（ref 0, スコア 0.4362）を選択。PASS（ref 1, スコア -0.1678）はPASSペナルティ免除が働きつつも、有効なCounterが存在するため確実に迎撃。

- **評価:** Counterおよびクイック防御の基礎ロジックは極めて安定しており、合格水準に達している。

### カテゴリ C: 攻撃魔法 (BP-AI-09 〜 BP-AI-11)
- **合理的だった点:**
  - **BP-AI-10（対抗可能性考慮: P1）:** 相手手札0枚時（対抗不能）の投擲スコア（0.1816）が、相手手札5枚時（Counter警戒）の投擲スコア（0.1792）よりも高く（差分 +0.0024）、相手の手札状況に応じたリスク評価が機能している。

  - **BP-AI-11（ハンデスによる妨害: P1 / AMBIGUOUS）:** 序盤の相手手札4枚に対し、ハンデス（ref 0, スコア -0.1659）より手札温存（ref 1, スコア -0.0655）を選択。温存自体は戦術として一理あるが、消極的すぎる嫌いがある。

### カテゴリ D: 召喚・攻撃 (BP-AI-12 〜 BP-AI-15)
- **合理的だった点:**
  - **BP-AI-12（Jokerのリアニメイト: P1）:** 墓地の最強カードJokerをリアニメイト（ref 0, スコア 0.2314）し、盤面優勢を確立。

- **判断ミス・致命的課題:**
  - **BP-AI-14（無謀なアタックの回避: P0 / FAIL）:**
    - 自軍に小型兵士（サイズ1）のみ、相手フィールドにチャージ状態の大型兵士（サイズ6）が構えており、相手ライフは15。

    - **根本原因:** アタック行動自体に強い正のベーススコアが付与されている一方、ブロッカーによる一方的返り討ちリスクを減点する特徴量・重みが欠落または不足している（原因C）。
    - **人間対戦への影響:** 人間プレイヤーが対戦した際、「なぜ勝てない大型兵士がいるのに自滅攻撃してきたのか？」と最も強い違和感・興ざめを与える**P0の致命的悪手**である。

- **合理的だった点:**
  - **BP-AI-16（手札温存: P2）:** コンボ用手札がある際、無意味な兵士召喚（ref 0, -0.1623）を避け手札温存（ref 1, -0.0704）を選択。

## 4. v7.2 と v7.3 の比較・評価

### 100%パリティの確認
今回の固定21シナリオ診断において、Gen 9 R4 v7.2 と Gen 9 v7.3 は、**全21シナリオで全く同一の選択行動、全く同一のスコア（ベース、戦術補正、最終スコア）**を記録した。

### パリティの理由
- Work 5-5B R2 / 5-5C で実装された通り、v7.3 の追加4特徴量（$t_{21} \sim t_{24}$: コスト支払いに関する特徴量）は、DNA上の重みが **0.0（ゼロ重み）** で組み込まれている。
- そのため、固定局面におけるスコア計算式は $\sum_{i=0}^{20} w_i t_i$ と全く同一となり、v7.2 と数学的に完全等価となる。

### コスト候補識別能力との関係
- Work 5-5C で確認された通り、v7.3 は内部的に24次元の特徴量ベクトルを計算しており、同一アクション内で複数のコスト支払い候補（どのカードを捨てるか等）が存在する場合に 93.55% の候補群を識別可能である。
- 今回の21シナリオの多くは「アクション種別の選択（アタック vs エンド、ブロック vs パスなど）」をテストしているため、ゼロ重みの下ではv7.2と同一の判断を出力した。

### 次期（Work 5-7B）の修正ベース選定
- **結論: Gen 9 v7.3 を修正ベースとして採用すべきである。**
- **理由:**
  1. 既存の戦術評価性能はv7.2と100%同等であり、回帰がない。
  2. すでに24次元のDNA構造およびコスト候補識別機構が整っており、今後のコスト重み付けや戦術修正を単一のコードベースで安全に行える。
  3. v7.2に戻すと、Work 5-5で完成させたコスト特徴量機構を破棄することになり、将来の拡張性が損なわれる。

## 5. Work 5-7B への優先順位付き改善候補一覧

スタンダード＋パックAIを「遊べる品質」として完成させるため、修正対象を工数対効果が高い項目に厳選する。

### 【必須修正】P0: 無謀アタックの自滅ペナルティ（BP-AI-14）
- **現象:** 相手の場に自軍より遥かに大きい兵士（例: サイズ6）が立っているにもかかわらず、自軍の小型兵士（サイズ1）で特攻して一方的に犬死する。
- **改善方針:**
  - アタック判定時、相手フィールドに「そのアタッカーを一方的に撃破可能なブロッカー」が存在し、かつ相手ライフを削り切れない場合、アタック行動に自滅ペナルティ（減点）を与える。
- **工数感:** **小**（`GenericTacticalEvaluator` または戦術補正での条件判定追加）
- **期待効果:** **絶大**（人間が最も不自然に感じる「AIの特攻自滅」を完全に撲滅）。

### 【優先修正】P1: 大型脅威に対する攻撃魔法・除去のスコア引き上げ（BP-AI-09）
- **現象:** 相手の強力な大型兵士（サイズ7〜10）に対し、死の槍のコスト消費を嫌ってPASSしてしまう。
- **改善方針:**
  - 相手のサイズ5以上の兵士を対象とする破壊・除去アクションに対し、目標サイズに応じたボーナス加点（またはコストペナルティの緩和）を適用する。
- **工数感:** **小**
- **期待効果:** **大**（相手の大型フィニッシャーを適切に除去できるようになり、盤面の攻防が引き締まる）。

### 【優先修正】P1: 自ライフ安全圏における小型兵士ブロックの抑制（BP-AI-05）
- **現象:** 自ライフが15あり安全な状況で、相手のサイズ1攻撃に対して自軍の貴重な小型兵士を差し出して無駄死にさせてしまう。
- **改善方針:**
  - 自ライフが安全域（例: 10以上）であり、相手の攻撃ダメージが軽微（1〜2点）な場合、ブロックしない選択（スルー/PASS）のスコアを引き上げるか、小型兵士のブロックに小さな消耗ペナルティを付与する。
- **工数感:** **小**
- **期待効果:** **中**（人間上級者のような「ライフで受けてリソースを温存する」自然なプレイが実現）。

### 【後回し候補】P2: アクション優先順序および防壁評価の調整（BP-AI-18, 19, 21）
- **内容:**
  - アタック可能兵士がいるフェーズでのリアニメイト先走り抑制（BP-AI-21）
  - 防壁設置・防壁破壊に対するコスト負バイアスの緩和（BP-AI-18, 19）
- **工数感:** 中
- **判断:** 今回の完成目標（遊べる水準）に対しては影響が小さいため、Work 5-7Bでは必須とせず、余力があれば対応する。

## 6. 必須5質問（Q1〜Q5）への回答

### Q1: スタンダード＋パックAIとして、現状のGen 9は「遊べる品質」に達しているか。
**回答: 概ね「遊べる品質」の基礎（合格水準）に達しているが、1点の致命的悪手（P0）が残っている。**
- 防御（致死回避・相打ち・合算ブロック・大型ブロッカー選択）、Counter（投擲・死の槍への的確な対抗、回避）、有利アタック、パック開封、Jokerリアニメイトなど、21シナリオ中12シナリオで的確かつ合理的な判断ができています。
- ただし、相手に大型兵士がいる状況での「無謀な犬死特攻（BP-AI-14）」という明確な致命的悪手があるため、人間が対戦した際に「なぜ自滅攻撃をしたのか？」と強い違和感を与えます。この1点を解消すれば、十分に手応えのある「遊べる対戦相手」として完成します。

### Q2: 21シナリオ中、現時点で合理的な判断ができているものは何件か。
**回答: 12件（57.1%）が明確に合理的（PASS）と判定された。**
- **PASS (12件):** BP-AI-01, 02, 03, 04, 06, 07, 08, 10, 12, 13, 17, 20
- **FAIL (2件):** BP-AI-09（死の槍見送り）, BP-AI-14（無謀アタック強行）
- **AMBIGUOUS (7件):** BP-AI-05, 11, 15, 16, 18, 19, 21（状況や戦略によって許容される判断）
- 明らかな不合理（FAIL）はわずか2件にとどまっており、AIの基本判断骨格は堅牢です。

### Q3: 人間が対戦して「明らかに不自然・致命的」と感じる行動は何か（P0・P1から挙げる）。
**回答: 以下の3点が挙げられる（特に1が致命的）。**
1. **【P0 / 致命的】無謀な犬死アタック（BP-AI-14）:** 相手フィールドに勝てない大型ブロッカーがいるのに、小型兵士で突撃して一方的に破壊される行動。
2. **【P1 / 不自然】敵大型兵士への死の槍見送り（BP-AI-09）:** 相手の主力大型兵士を除去できる手札があるのに、コスト消費を嫌って温存してしまう行動。
3. **【P1 / やや不自然】安全圏での過剰ブロック（BP-AI-05）:** 自ライフ15で余裕があるのに、相手の1点攻撃に対して小型兵士を差し出して消耗してしまう行動。

### Q4: v7.2とv7.3のどちらを次期（Work 5-7B）の修正ベースにすべきか。
**回答: Gen 9 v7.3 を修正ベースとすべきである。**
- v7.2 と v7.3 は今回の固定シナリオ診断において 100% 同一の判断を出力しており、性能低下や回帰はありません。
- v7.3 は 24次元の戦術・コスト特徴量構造および 93.55% のコスト候補識別能力を内蔵しているため、今後の拡張性と修正作業の統一性の観点から、v7.3 をベースにするのが最も安全かつ効率的です。

### Q5: Work 5-7Bで修正すべき項目を、工数対効果が高い順に3〜5点に絞ると何か。
**回答: 以下の3点に絞ることを推奨する。**
1. **無謀アタックの自滅ペナルティ（必須 / P0 / 工数小・効果絶大）:** 相手大型ブロッカーがいる局面でのアタック自滅を抑制。
2. **大型脅威に対する攻撃魔法・除去の評価引き上げ（優先 / P1 / 工数小・効果大）:** 相手大型兵士への死の槍などの除去アクションを優先。
3. **自ライフ安全時の小型兵士ブロック抑制（優先 / P1 / 工数小・効果中）:** ライフ余裕時に相手小型攻撃をスルー（PASS）して戦力を温存。
